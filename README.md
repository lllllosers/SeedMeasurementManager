草种测定管理是一套面向草种子发芽试验与根/苗长测定的 Windows 桌面辅助工具。软件以 Microsoft Excel 模板作为数据后端，通过 Windows PowerShell 5.1 + WinForms + Excel COM 实现发芽巡检、今日测定任务、3/7/14 DAG 根苗长录入、数据校验与状态跟踪。

## 主要功能

- 今日任务：自动汇总当天 3DAG / 7DAG / 14DAG 测定任务，支持搜索、阶段筛选和双击跳转。
- 发芽巡检：按物种查看前 10 个测定样本槽位；记录新发芽种子的日期与原始坐标；允许后补坐标。
- 根苗长录入：支持连续录入、Enter 键流转、保存并下一条；支持数值和 `NA`；已有数据覆盖前二次确认。
- Excel 集成：所有实验数据仍保存在 Excel 中；软件不建立独立数据库。
- 数据安全：工作簿只读检测、保存校验、关闭时释放 Excel 后台进程、错误日志。
- 本地运行：软件本身不主动上传实验数据。

## 运行环境

- Windows 10 / Windows 11
- Windows PowerShell 5.1
- Microsoft Excel 桌面版
- **推荐 Microsoft 365 或 Excel 2021 及以上版本**  
  模板使用 `LET`、`XLOOKUP` 等较新的 Excel 函数。
- 不需要安装 Python。

> 不建议使用 WPS、网页版 Excel 或删除/重命名模板中的核心工作表。

## Excel 模板应该放在哪里？

**建议把“母版”放在软件目录下的 `templates/` 文件夹。**  
这样别人拿到软件时能立刻找到标准模板，同时又能与日常实验数据分开。

**不要直接在母版上开展实验。** 每次开展新试验时：

1. 复制 `templates/模板-种子发芽试验结果统计表.xlsx`；
2. 将副本重命名，例如：
   `种子发芽试验结果统计-20260814-批次A.xlsx`；
3. 可将工作副本放在 `data/` 文件夹，也可以放在任意实验数据目录；
4. 启动软件，点击 **“选择 Excel”**，选择该工作副本；
5. 后续所有发芽巡检与根苗长数据均写入该工作副本。

软件会记住上次使用的工作簿路径。切换实验时请重新点击“选择 Excel”。

## 模板结构

模板包含 4 张核心工作表，名称不得随意修改：

### 1. `种子信息`
保存物种编号、物种名称、拉丁名、来源、分区等基础信息。  
核心编号建议保持 `001`、`002`……的三位编号格式。

### 2. `根-苗长统计表`
核心字段：

- A：物种编号
- B：物种名称
- C：种子编号
- D：样本ID（勿动）
- E：置床时间
- F：发芽时间
- G/H/I：根长 3DAG / 7DAG / 14DAG
- J/K/L：苗长 3DAG / 7DAG / 14DAG

软件会向 F、G:L 写入数据。D 列样本ID及公式结构不要手工修改。

### 3. `测定时间计划表`
用于自动计算发芽后的 3DAG、7DAG、14DAG 日期、完成状态和下一次任务。

关键字段：

- D：样本ID
- E：发芽时间
- F/G/H：3DAG / 7DAG / 14DAG 日期
- I/J/K：对应阶段完成状态
- L：下一次测定
- M：测定状态
- **N：备注 / 原始坐标**

发芽巡检中的坐标（如 `E3`、`A5`、`B10`）写入 N 列。

### 4. `今日任务`
Excel 内部的动态任务视图。软件另有自己的“今日任务”页面。  
此工作表主要用于直接打开 Excel 时查看，不建议人工改写其公式区。

## 发芽试验的数据模型

每个物种在一个培养皿内摆放 **50 粒种子**，物理坐标为：

```text
A1 ~ A10
B1 ~ B10
C1 ~ C10
D1 ~ D10
E1 ~ E10
```

软件及模板只跟踪**前 10 个发芽种子**作为后续根/苗长测定对象。

例如某物种今天最先发芽的是 `E5`，则：

```text
001-1 -> 原始坐标 E5
```

第二个发芽的是 `A7`，则：

```text
001-2 -> 原始坐标 A7
```

依次直到 `001-10`。当某物种达到 10/10 后，该物种不再需要继续做发芽巡检；这 10 个样本随后按各自发芽日期进行 3/7/14 DAG 根苗长测定。

原始坐标允许暂时不记录，后续可补录；未补坐标不会阻断新的发芽记录。

## 快速开始

1. 复制 Excel 母版并重命名为本次试验工作文件。
2. 双击 `start.vbs` 启动软件。
3. 首次使用或切换试验时点击 **“选择 Excel”**。
4. 在“发芽巡检”中记录新发芽位置与日期。
5. 在“今日任务”查看当天需要测定的样本。
6. 双击任务，或进入“根苗长录入”输入根长、苗长。
7. 完成后直接关闭软件，等待软件保存并释放后台 Excel。
8. 如需手工打开同一个 Excel，请先完全退出软件。

## 根苗长输入规则

- 单位：mm
- 接受非负数字，例如 `0`、`12`、`12.35`
- 接受 `NA`，表示已检查但无有效测量值
- 负数和其他文本会被拒绝
- 已有根/苗长数据时，软件要求明确确认后才能覆盖

## 数据安全建议

- 母版只作为模板保存，不直接记录正式试验。
- 每个试验使用独立 Excel 副本。
- 建议每日或每个测量批次结束后备份工作簿。
- 软件运行期间不要同时用 Excel 手工编辑同一个工作簿。
- 软件关闭时会主动保存并退出其后台 Excel 实例。
- 如果电脑异常关机导致文件仍显示“正在使用”，先确认没有其他 Excel 文档正在编辑，再在任务管理器中处理残留的 `EXCEL.EXE`。

双击：

```text
start.vbs
```

双击：

```text
diagnose.bat
```

## 已知限制

- 仅支持 Windows + Microsoft Excel 桌面版。
- 当前为单机、单用户模式。
- 不支持多人同时编辑同一实验工作簿。
- 核心工作表名、关键列和样本ID结构必须保持与模板一致。
- 当前不提供自动版本化备份、云同步或数据库后端。
- 发芽试验按每物种最多 10 个后续测定样本设计。
