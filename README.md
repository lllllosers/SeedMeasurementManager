草种测定管理是一套面向草种子发芽试验与根/苗长测定的 Windows 桌面辅助工具。

软件以 Microsoft Excel 模板作为数据后端，通过 Windows PowerShell 5.1 + WinForms + Excel COM 实现：

- 培养皿级发芽巡检与发芽率统计
- 前 10 个发芽样本管理
- 今日测定任务
- 3 / 7 / 14 DAG 根苗长连续录入
- 根苗长历史实时核对与安全纠错
- 数据校验与状态跟踪

所有实验原始数据仍保存在 Excel 工作簿中，软件不建立独立数据库。


## 主要功能

### 发芽巡检

- 按物种 / 培养皿记录每次巡检的“本次新增发芽”数量。
- 自动计算累计发芽数和当前发芽率。
- 支持同一培养皿同一天多次巡检。
- `0` 是有效巡检结果，表示“已检查，但本次无新增发芽”。
- 未产生巡检记录则表示“未检查”。
- 首次巡检时设置培养皿置床日期，后续自动沿用。
- 支持“0新增并下一物种”，提高连续巡检效率。
- 自动限制累计发芽数不得超过总种子数。

### 根苗长录入与历史纠错

- 支持 3DAG / 7DAG / 14DAG 根长、苗长连续录入。
- 支持 Enter 键连续操作和“保存并下一条”。
- 支持非负数值以及 `NA`。
- 录入时实时显示当前物种全部测定样本的历史数据。
- 历史表显示种子编号、发芽日期以及各 DAG 的根长和苗长。
- 当前样本、当前 DAG 和实际输入位置使用分层高亮辅助人工核对。
- 支持按样本 ID、物种编号、物种名称进行查询。
- 无今日任务的物种仍可单独查看完整测定历史。
- 双击已有测定值可进入历史修改模式。
- 修改时同时载入该样本对应 DAG 的根长和苗长，并在写入前再次确认。
- 支持 Enter 确认修改、Esc 取消修改。
- 支持直接切换历史纠错目标，并保护尚未保存的修改。
- 支持清除某一 DAG 的整组根长和苗长数据，使该阶段恢复为未完成状态。
- 历史修改或清除完成后自动恢复原来的实验任务或历史查看位置。
- 发芽日期在本版本中保持只读，不属于根苗长纠错范围。

### 今日任务

- 自动汇总当天需要执行的 3DAG / 7DAG / 14DAG 测定任务。
- 支持搜索。
- 支持 DAG 阶段筛选。
- 支持双击任务跳转到根苗长录入页面。

### Excel 集成与数据安全

- 所有实验数据继续保存在 Excel 中。
- 软件不建立数据库。
- 使用内存缓存减少频繁 Excel COM 读取。
- 工作簿只读状态下拒绝写入。
- 保存后检查 Excel 是否真正落盘。
- 关闭软件时主动保存并释放后台 Excel 进程。
- 保存失败、格式错误等异常写入 `error.log`。

### 本地运行

软件本身不主动上传实验数据，实验工作簿保存在用户指定的本地目录中。


## 运行环境

- Windows 10 / Windows 11
- Windows PowerShell 5.1
- Microsoft Excel 桌面版
- 推荐 Microsoft 365 或 Excel 2021 及以上版本
- 不需要安装 Python

Excel 模板使用 `LET`、`XLOOKUP` 等较新的函数，因此不建议使用过旧版本的 Excel。

> 不建议使用 WPS、网页版 Excel，或自行删除 / 重命名模板中的核心工作表。
